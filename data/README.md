# Data

This directory is reserved for local survey files used when running the workflow.

The expected input is respondent- or household-level tabular survey data. A typical file includes identifiers, survey weights, cluster or sampling-unit fields, strata where available, binary questionnaire items for index construction, and covariates for modelling.

Raw survey files and derived respondent-level outputs should normally remain outside version control unless they are small, anonymised, and clearly shareable under the data licence.
